# Raj Bhokare - Portfolio Website

A modern, high-performance developer portfolio built with React 18, Vite, TypeScript, Three.js, and Lenis smooth scrolling.

---

## 🚀 Local Development & Build

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Dev Server**:
   ```bash
   npm run dev
   ```

3. **Build Production Bundle**:
   ```bash
   npm run build
   ```

4. **Preview Production Build**:
   ```bash
   npm run preview
   ```
